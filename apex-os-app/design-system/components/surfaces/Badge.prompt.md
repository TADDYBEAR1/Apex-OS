Capsule tag for exercise categories and status. Three semantic categories carry fixed colors.

```jsx
<Badge tone="strength">Strength</Badge>
<Badge tone="bodyweight">Bodyweight</Badge>
<Badge tone="endurance">Endurance</Badge>
<Badge tone="neutral">1RM</Badge>
```

Tones: `strength` (orange), `bodyweight` (green), `endurance`/`cyan` (cyan), `neutral` (grey).
