Round, hairline icon button used for inline actions (close, delete, add); tone shifts the ring + glyph color.

```jsx
<IconButton label="Close" tone="muted">✕</IconButton>
<IconButton label="Delete" tone="danger" size={28}>✕</IconButton>
<IconButton label="Add" tone="primary">+</IconButton>
```

Tones: `muted` (default), `primary` (cyan), `danger` (orange). `size` is the pixel diameter (default 32).
