Apex OS button — pill-shaped, uppercase, glassy. Primary lifts to cyan on hover.

```jsx
<Button variant="primary">Log Readiness</Button>
<Button variant="solid" size="lg" fullWidth>Start Mission</Button>
<Button variant="surface">Export Plan</Button>
<Button variant="ghost" size="sm">Cancel</Button>
```

Variants: `primary` (glass pill, the default), `solid` (filled cyan, highest emphasis), `surface` (neutral rounded-rect, lives inside cards), `ghost` (low-emphasis). Sizes `sm | md | lg`. Pass `icon` for a leading glyph and `fullWidth` to stretch.
